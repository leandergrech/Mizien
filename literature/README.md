# Literature

One folder per claim. Each holds:

- `references.bib`: every source relied on, in BibTeX;
- `notes.md`: how each source was accessed (full text, abstract, second-hand) and the finding used;
- `open-access/`: PDFs that are open access only.

## Policy

- **Do not commit paywalled papers.** Store the citation, DOI, link and our own notes.
- Mark second-hand sources as such in `notes.md` and in the `note` field of the BibTeX entry.
- Record the date a source was accessed.
- Search order: peer-reviewed literature, then independent datasets, then regulator and EU reports, then news.
