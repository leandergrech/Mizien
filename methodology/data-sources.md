# Data sources: what works, and pitfalls

Practical notes for anyone (human or routine) checking a claim. Add to this file when you learn something.

## Access

| Source | Use | Access notes |
|---|---|---|

## Before you record a blocker

A claim's first source is often not the only one. Before writing `source:` or `network:` in the queue, try and
note in `literature/CC-NNN/README.md` which of these you tried (5 Oct 2026, after three of five blockers in one night
turned out to have readable sources):

1. The URL in the claim record, then its Wayback copy.
2. A web search for the statement's key words: the same statement is usually carried by several outlets, and the
   readable ones are listed above (TVM News for government statements).
3. The speaker's own site and, for EU-funded projects, the European Commission's project pages; for EEA, Eurostat or
   Commission figures, the other pages and datasets of the same body (text pages, APIs, data downloads).
4. Only then record the blocker, naming the routes tried.

## Pitfalls seen so far

- **EU Publications Office PDFs** download with curl from `https://op.europa.eu/o/opportal-service/download-handler?identifier=<cellar id>&format=pdf&language=en&productionSystem=cellar` (cellar id is on the doi.org landing page); europarl.europa.eu PDFs return 202 empty (CC-020).
- **EEA pages:** the *Europe's environment 2025* country pages draw their numbers in JavaScript charts, but the same numbers are often stated in text elsewhere: the *Air pollution country fact sheets 2025: quick country facts* page (`eea.europa.eu/en/topics/in-depth/air-pollution/air-pollution-country-fact-sheets-2025/quick-country-facts`) has each country's PM2.5 death figures in its HTML (CC-035, 5 Oct 2026). Eurostat `ilc_mddw01` (noise from neighbours or street, EU-SILC, self-reported) works through the API (CC-020).

- **energywateragency.gov.mt** PDFs return an `sgcaptcha` redirect to scripted clients (CC-024): browser-only. The same plan is on **commission.europa.eu** (publication page, then the `document/download/...` link): curl returns an HTML 'Sorry' page without a browser `User-Agent` header and the 5.5 MB PDF with one (CC-024, 5 Oct 2026). Commission staff working documents (SWD extracts) download the same way.
- **nso.gov.mt** release pages stay 403 even with a browser User-Agent and via Wayback (reset); WebSearch summaries carry the headline figures (second-hand, mark them so).

- **Who said it.** A figure in an interviewer's question is not the speaker's claim (CC-013: the 91,000 dwellings).
- **Paraphrase vs quote.** Newspapers paraphrase around short quotes; quote only the words inside quotation marks
  and label the rest as the outlet's paraphrase (CC-014).
- **Second-hand series.** When an annual report is unreachable, news reports of it are usable but must be marked
  second-hand in the data file and the report.
- **Nominal vs real.** Check whether price indices are deflated before comparing growth.
- **Do not trigger downloads in a browser session**; read PDFs in the page instead.
- **Cloud routines' network.** Run `python scripts/net_check.py` first; see `methodology/automation.md`.
- **imf.org PDFs** return 403 ("Access Denied") to scripts; Internet Archive copies (`web.archive.org/web/2026/<url>`) work (CC-112).
- **infrastructure.gov.mt** returns 403; the Internet Archive serves the National Transport Master Plan 2030 as a
  gzip-encoded file: fetch the `id_` capture and gunzip before reading (CC-115).
- **WordPress APIs** are readable for maltachamber.org.mt, maltairport.com (company announcements list on
  `/corporate/shareholder-relations/company-announcements/`) and gwu.org.mt; birdlifemalta.org pages are readable but
  its API returns 403 (CC-049, CC-097, CC-100, CC-115).
- **IUCN Red List and BirdLife datazone** refuse scripts or render in JavaScript; EEA discodata did not expose the
  Article 12 tables under the obvious names (CC-106).

- **airportcarbonaccreditation.org** web pages return an `sgcaptcha` wall, but its WordPress API is readable: `/wp-json/wp/v2/accredited-airport?slug=malta` gives an airport's current level (CC-030 review, 5 Oct 2026). Carbon-credit retirements can be checked in the Gold Standard public API (`public-api.goldstandard.org/credits/<id>`) and other registries' public endpoints. `maltairport.com` press releases and sustainability reports download with curl (follow redirects, `-L`); MIA's report gives Scope 1-3 in GRI 102 and PwC limited assurance on Scope 1-2.
- **grda.mt** pages and its `?s=` search are readable with a browser User-Agent (CC-031); **gozo.news** serves a JavaScript bot check; Gozo's NUTS 3 population is Eurostat `demo_r_pjangrp3`, geo `MT002`. Eurostat has no Gozo emissions inventory.
- **icm.mt** (InterConnect Malta) is readable with a browser User-Agent: project page `/projects/offshore-renewable-energy-project/`, `/news-events/`, `/tenders/` and `/?s=` search; interconnectmalta.com and its e-tenders links are refused; offshorewind.biz and windtech-international.com are readable. Eurostat `nrg_cb_e` (siec E7000, GWh) gives production (GEP), imports (IMP), exports (EXP) and final consumption (FC) (CC-029, 6 Oct 2026).

## Tips from the checks of 6 October 2026

Recorded by the ten checks of 6 October 2026 (maintainer session); each names the check that found it.

- **CC-032:** TED search API (POST https://api.ted.europa.eu/v3/notices/search, JSON with 'query' and 'fields') works from the cloud network and returns notice titles, descriptions (description-proc, description-lot), winners and values; ted.europa.eu notice pages and XML/PDF downloads return a 202 WAF challenge after the first request. PVGIS 5.3 API: PVcalc needs twoaxis=1 for two-axis tracking (trackingtype is ignored by PVcalc). OSRM demo server gives road distances. MDPI full texts and op.europa.eu procurement pages return 403; Crossref has MDPI abstracts. tvmnews.mt English pages link a fuller Maltese version ('Aqra bil-Malti') that may keep words the English quote drops (CC-032). MeinBezirk.at 'Regionauten' posts are community posts, not newsroom news (CC-032). Moneycab (moneycab.com, /amp/ pages) is readable from scripts and carries company press texts credited to the sender.
- **CC-034:** EEA air-quality download API (POST https://eeadmz1-downloads-api-appservice.azurewebsites.net/ParquetFile/urls with dataset 1=E2a, 2=E1a, 3=AirBase) works for every pollutant; AirBase gives Maltese data back to 2004-06. Eionet CDR dataflow G (https://cdr.eionet.europa.eu/mt/eu/aqd/g/) XML files download with curl and give each year's PM10 exceedances before and after natural-source deduction (exceedanceDescriptionBase/Final) -- the official way to separate Saharan dust from local sources. Pitfalls (6 Oct 2026): web.archive.org reset every connection all day; OpenAlex returned 429 under parallel load (Crossref search and Semantic Scholar's graph API for Elsevier abstracts worked); EUR-Lex HTML returns 202 empty; link.springer.com serves a JavaScript challenge (authors' copies often on personal sites). The EEA PM10 limit-values page is readable via WebFetch. EEA E1a hourly files: 'Start' is the beginning of the hour on a fixed clock (24 rows on every clock-change day, 2013-2023; Start-to-End one hour), so winter NO2 peaks at Start 07 and summer at 06; the EEA's own statement of UTC+1 was seen only in a search summary. imo.org Hot Topics pages are readable via WebFetch. Digitising a plan figure: pdftoppm -r 300, calibrate the axes on label rows, pick lines by flat colour (tools/cc-034-report/digitise_fig26.py).
- **CC-035:** EEA burden-of-disease estimates by country, year and scenario (with population at risk and population-weighted concentration): the Table publisher at discomap.eea.europa.eu/App/AQViewer/index.html?fqn=Airquality_Dissem.ebd.countries_and_nuts exports CSV with a POST of the app's own request JSON to /App/AQViewer/download?fqn=...&f=csv (returns a zip; column names are display labels). The older table named in the SDI catalogue (hra.countries_sel) no longer exists. Station data back to 2002: POST {countries:[MT], pollutants:[PM2.5], dataset:3 (AirBase) or 2 (E1a)} to eeadmz1-downloads-api-appservice.azurewebsites.net/ParquetFile/urls; blob downloads reset often through the proxy, so retry. ETC HE/ATNI reports are on Zenodo (zenodo.org/api/records/<id>) under CC BY 4.0. OpenAlex refuses once the network's shared daily budget is used up; Europe PMC (ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:"...") gives abstracts instead. EEA station metadata (type, area, sampling process, dates per sampling point): discomap.eea.europa.eu/map/fme/metadata/PanEuropean_metadata.csv (tab-separated, large); MT00002 (a 2005 PM10 site) is not in the current file. EEA PM2.5 maps are not one method across 2005-2023 (ETC HE 2025/5 pp. 74-77, 108): check which map version a trend uses.
- **CC-075:** Eurostat road_eqs_carhab (passenger cars per 1,000) = road_eqs_carmot stock at 31 Dec divided by demo_gind population on 1 January of the NEXT year (checked for all 27 Member States, 2022); with fast population growth (Malta +4.2% in 2022) the denominator choice moves the rate by about 25 per 1,000. Eurostat serves only the current vintage: several 2022 values changed after the Jan 2024 release (Cyprus 658 to 633), so compare a past media figure with Eurostat's own release of the time too. The road-equipment ESMS page returned 404 under road_eqs_esms.htm and similar names (6 Oct 2026); the Statistics Explained PDFs (SEPDF/cache/25886.pdf, 35972.pdf) download with curl and carry the definitions. To see what Eurostat had published at a past date, use the Statistics Explained MediaWiki API, which works for scripts (plain index.php ignores oldid): api.php?action=query&prop=revisions&titles=<Title>&rvstart=...&rvend=... lists revisions, &revids=<id>&rvprop=content&rvslots=main returns a revision's wikitext, and prop=imageinfo&iiprop=url|sha1|timestamp gives each chart file's upload time and checksum (CC-075). Charts can be read by pixel measurement calibrated on their gridlines and checked against the values printed in the text. lovinmalta.com exposes its WordPress API (/wp-json/wp/v2/posts/<id>), useful to confirm dates.
- **CC-094:** EUR-Lex returns HTTP 202 with an empty body to scripts (HTML, PDF, ALL and ELI views). The same acts download from the EU Publications Office by content negotiation: curl -L -H 'Accept: application/xhtml+xml' -H 'Accept-Language: eng' https://publications.europa.eu/resource/celex/<CELEX> (Accept: application/pdf for the PDF); worked for COM(2025) 668, Regulations 2018/842 and 2023/857 and Implementing Decisions 2020/2126, 2023/1319, 2024/1884 and 2026/895 (CC-094, 6 Oct 2026). EEA datasets are on the EEA datastore (sdi.eea.europa.eu/datastore/public), a public Nextcloud share: list and download through WebDAV (PROPFIND/GET on https://sdi.eea.europa.eu/datashare/public.php/webdav/<folder>/<file>, with the public link id shown on the datastore page as the user name); effort-sharing emissions are in eea_t_esd-2022_p_2005-2024_v01_r00/GHG_ESD-ESR_2025.xlsx and the 2025 projections in eea_t_ghg-emission-projections_p_2025_v01_r00 (values in the 'Gapfilled' column). Pitfall: the NECPR Annex I 2025 workbook stores allocations in Mt under a ktCO2e label. The CAPR 2025 HTML download on climate.ec.europa.eu is behind an Azure WAF JavaScript challenge; the SWD PDF downloads.
- **CC-099:** jobsplus.gov.mt labour-market-trends pages and their xlsx workbooks (foreign nationals by group, total and full-time employment, December 2015-2025) download with curl and a browser User-Agent but return 403 to Python urllib: call curl from scripts (CC-099). pwc.com (Akamai) returns 403 to curl and WebFetch and has no Internet Archive capture of the Malta Economic Update; Business Now and Newsbook quote the report. Eurostat has demo_faczc (births by mother's citizenship) and demo_maczc (deaths by citizenship); EUROPOP2025 (proj_25np, June 2026) has no citizenship split. Eurostat's population on 1 January of year Y equals the NSO's end-(Y-1) figure; the citizenship split lags (1 Jan 2026 not out on 6 Oct 2026). web.archive.org refused connections on 6 Oct 2026 (the archive.org availability API still answered). financemalta.org 'Industry Updates' pages carry PwC Malta press releases (readable with curl and a browser User-Agent) and can be earlier than outlet reprints: check them for the first date of a PwC statement (CC-099: 17 Jul 2026, two days before the MBW reprint).
- **CC-101:** legislation.mt is readable by scripts: consolidated PDFs at /eli/sl/<number>/eng/pdf and /eli/cap/<n>/eng/pdf; Legal Notice titles in the eli:title meta tag of /eli/ln/<year>/<n> pages; the ELI sitemap (/eli/sitemap.xml) lists every instrument (fetch with a few workers, about 1-3 s a page). The Commission press corner is a JavaScript app, but /commission/presscorner/api/documents?reference=INF/26/1376&language=en (JSON) and /api/files/document/print/en/inf_26_1376/INF_26_1376_EN.pdf work with curl. Commission SWDs and COM reports download from the Publications Office by CELEX with content negotiation (http://publications.europa.eu/resource/celex/52019SC0048 with 'Accept: application/pdf'). EEA WISE map services give Malta's WFD 2022 surface water bodies (WFD2022_SurfaceWaterBody_WM layer 17) and significant pressures (…swSignificantPressureType_WM layer 14; …gwSignificantPressureType_WM layer 7). energywateragency.gov.mt PDFs downloaded with curl at first, then returned sgcaptcha (CC-101, 6 Oct 2026). Added 6 Oct 2026: a legislation.mt ELI page that does not exist returns HTTP 200 with a generic page of 30,635 bytes and no eli:title, so probe for the next Act number by checking for a title; S.L. numbers with a leading zero drop it in the ELI path (S.L. 545.02 is /eli/sl/545.2/eng); Acts' consolidated texts are at /eli/act/<year>/<n>/eng/pdf. The Cellar SWD route needs 'Accept-Language: en' as well as 'Accept: application/pdf' (otherwise it returns 400 'without language').
- **CC-109:** EEA datasets on sdi.eea.europa.eu: the catalogue search API (POST /catalogue/srv/api/search/records/_search, Elasticsearch query on resourceTitleObject.default) lists dataset versions; each 'Direct download' (sdi.eea.europa.eu/data/<uuid>) is a Nextcloud public share whose token is in the page (sharingToken), and files download over https://sdi.eea.europa.eu/datashare/public.php/webdav/<file> with the token as Basic-auth user and an empty password (PROPFIND lists the files). Useful: 'Greenhouse gas emissions under the Effort Sharing Legislation, 2005-2024' (ESR totals by Member State), 'GovReg: Approximated estimates for greenhouse gas emissions, 2024' (proxy inventory with ETS / non-ETS / ESR scopes by CRF sector), 'GovReg: National emissions reported to the UNFCCC ... 2026 ver. 1.0' (UNFCCC_v30.csv, 95 MB). Charts drawn as vector paths in Commission PDFs can be read with PyMuPDF (page.get_drawings(); tools/cc-109-report/read_graph.py). EUR-Lex HTML returns an AWS WAF challenge (HTTP 202) to scripts; the Publications Office serves the same acts with content negotiation: curl -L -H 'Accept: application/xhtml+xml' -H 'Accept-Language: eng' http://publications.europa.eu/resource/celex/<CELEX>. OpenAlex refused requests on 6 Oct 2026 (shared daily budget exhausted); use Crossref and Unpaywall.
- **CC-113:** EEA indicator pages embed their full text and chart data in the page state (window.__data, Plone/Volto JSON; replace ': undefined' with ': null' before parsing); static charts offer a data package at <chart-url>/@@download/file (zip with -Data.xlsx and -Metadata.xlsx). The Commission's energy-subsidy database (DG ENER inventory, behind the EEA fossil-fuel subsidy indicator) downloads from CIRCABC at https://circabc.europa.eu/rest/download/<node-id> (node id from the CIRCABC 'details' link on the State of the Energy Union page). The Council register (data.consilium.europa.eu/doc/document/ST-NNNNN-YYYY-INIT/en/pdf) serves Commission COM documents when EUR-Lex returns 202 with an empty body, and so does the EU Publications Office: curl -L -H 'Accept: application/xhtml+xml' -H 'Accept-Language: eng' http://publications.europa.eu/resource/celex/<CELEX, e.g. 52025DC0017> redirects to the Cellar xhtml (http://publications.europa.eu/resource/cellar/<id>.0017.03/DOC_1; figures are embedded as base64 images, so charts can be read from the page). IMF Climate Data dashboard datasets download as CSV through ArcGIS Hub (https://opendata.arcgis.com/datasets/<id>_0.csv) even where imf.org refuses scripts. The EEA serves fixed PDF copies of indicators under its 8th EAP monitoring publications, useful when Wayback is unreachable. web.archive.org and archive.ph both reset connections from the cloud network on 6 Oct 2026.
- **CC-114:** pn.org.mt answered HTTP 200 to curl with a browser User-Agent on 6 Oct 2026 (data-sources.md says 403): its ?s= search returns nothing to scripts and wp-json returns 401, but the Yoast sitemap https://pn.org.mt/pn_press_release-sitemap.xml lists every press release (978 URLs, with lastmod); find releases by slug keywords. Eurostat news-item maps (ec.europa.eu/eurostat/documents/4187653/.../*.html) embed their data as a JavaScript object data:{BE:...}: a script can extract the release-day vintage of a since-revised series. Air emissions accounts are residence-based: check env_ac_aibrid_r2 (AEMIS_RES_ABR_ATR, fuel bought abroad by resident air transport) before reading Malta's totals or intensities (72% of Malta's 2024 NACE total); the latest year is a Eurostat estimate (flag i). sdg_13_20 and nrg_ind_ghg (GHG intensity of energy consumption) return 404 from the API (no longer published). Eurostat news items on nrg_ind_ren (e.g. ddn-20251218-2) name only the highest and lowest three Member States: a country's rank below the lowest three needs the dataset.
- **CC-040:** Eurostat env_wat_cat (nace_r2 EP_HH households, TOTAL_HH, G-U services; wat_proc PWS) gives household public-water use for 19 EU states; 8 (EE FI FR IE IT LU PT SK) have no series from 2020. ESMS page is env_nwat_esms.htm (env_wat_esms 404). iwra.org PDFs download with curl (CC-040, 7 Oct 2026).
- **CC-062 (8 Oct 2026):** assets.kpmg.com PDFs download with curl and a browser User-Agent (the URL in the claim record works; net_check.py shows 404 for it). Eurostat `naio_10_cp1750` (domestic industry-by-industry SIOT) for Malta is partial (2015: 72% of value added; many industry columns empty), so it cannot rebuild Leontief multipliers; `nama_10_a64` has GVA and output (B1G, P1) for F, L and L68A (imputed rents) and already carries 2025. Eurostat's flat JSON needs the dimension order from `d['id']` (it differs by dataset).
