# Corrections policy

Errors are corrected openly. Each report carries a version number and a revision log (Appendix B). A correction that
changes a verdict, a figure or an attribution is announced in the log with the date and what changed. We do not edit
history silently.

Every version, correction and clarification is also recorded in the claim's research log (`history:` in
`claims/CC-NNN/claim.yml`), dated when the research was done. The site lists them all on its Corrections page
(https://leandergrech.github.io/Mizien/corrections/), shows each correction or clarification at the top of the
check it affects, and includes them in the updates feed.

To request a correction or contest a verdict, open an issue using the **Contest a verdict** form and include the
evidence. The target response time is a proposal: edit this file to set the one the project commits to.
