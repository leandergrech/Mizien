# CC-141 data

- `eurostat_demo_find_tfr.csv`: total fertility rate (indic_de TOTFERRT) for the 27 Member States and EU27_2020,
  2000-2024, from the Eurostat API (dataset demo_find, updated 13 Nov 2026, retrieved 17 Nov 2026). `flag` is Eurostat's
  status code (b break, e estimated, p provisional, N not for publication).
- `ranks.csv`: Malta's rank from the lowest in each year with all 27 values (written by `tools/cc-141-report/calc.py`).
- `checks.csv`: the figures used in the report.
