# CC-013 data

- `eurostat_housing.csv`: Eurostat prc_hpi_a (nominal house prices), tipsho10 (deflated), sts_cobp_a (permit
  index), demo_gind (population), ilc_lvho07a (housing cost overburden), ilc_lvho05a (overcrowding); Malta and EU-27;
  retrieved 3 Oct 2026 from the Eurostat dissemination API.
- `pa_approved_dwellings.csv`: Planning Authority, Approved Dwelling Units 2007-2025, read 3 Oct 2026.
- `census2021_dwellings.csv`: NSO Census 2021, vol. 2, dwelling stock and occupancy.
- `checks.csv`: written by `tools/cc-013-report/calc.py`.
