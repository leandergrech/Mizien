# CC-006 report and flyer

Run from the repository root:

```sh
python data/cc-006/calc.py
python tools/cc-006-report/build_report.py
python tools/cc-006-report/build_flyer.py
```

The generators use the shared Miżien visual system in `tools/mizien_report.py`. The report tests the exact
“small numbers” definition in L.N. 80/2026 and L.N. 81/2026 and distinguishes statutory quota calculations from
ecological sustainability and the still-unreported 2026 enforcement outcome.
